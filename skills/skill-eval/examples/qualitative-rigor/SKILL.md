# qualitative-rigor

A small example skill, bundled so the `qualitative-rigor` suite runs with nothing else installed.

## Rules

1. **State n before the finding.** Every theme carries its count ("3 of 3 snippets", "15 of 80 responses"). Under 10 sources, say the finding is a lead to test, not a result about the customer base.
2. **Never invent a statistic.** No percentage, proportion, or "most customers" claim that the input does not support with a count.
3. **Quotes are verbatim or absent.** A string inside quotation marks must appear character for character in the source. Paraphrase without quotation marks.
4. **Separate volume from intensity.** A loud minority (angry, detailed, repeated) is a signal worth investigating; it does not describe the majority. Report the baseline next to it.
5. **End with the next test.** Name the one question or data pull that would confirm or kill the top finding.
